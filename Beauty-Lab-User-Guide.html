PRIVACY & LIMITS

安全、隐私与适用边界Security, Privacy and Practical Limits

本地优先不等于所有网页都能无损反向编辑。Local-first does not mean every web page can be round-tripped perfectly.
文件只在本机浏览器处理Files are processed only in your local browser

工具不上传源 HTML，不调用 API，也不依赖 CDN。脚本、内联事件和危险链接在修改画布中保持禁用，只在隔离预览与导出结果中运行；同步只传回当前页面 DOM，不允许预览读取编辑器数据。The tool does not upload source HTML, call APIs or depend on a CDN. Scripts, inline events and unsafe links stay disabled on the Edit canvas and run only in isolated Preview and exports. Sync returns only the current page DOM; Preview cannot read editor data.

React / Vue

运行时组件和 Shadow DOM 不保证无损回写。优先使用 AI 生成的静态、自包含 HTML。Runtime components and Shadow DOM are not guaranteed to round-trip. Prefer static, self-contained AI HTML.

Canvas

Canvas 内的文字、图例和数据不能直接编辑，只能调整整个元素尺寸并在预览中验证。Text, legends and data inside Canvas cannot be edited directly. Resize the whole element and verify in Preview.

SVG

简单 SVG 可整体选择和缩放；复杂路径建议保持原结构，不要拆分。Simple SVG can be selected and resized as a whole. Keep complex paths intact.

动态脚本Dynamic scripts

普通动态 DOM 可通过预览同步；React/Vue 持续重渲染、Shadow DOM、跨域 iframe 及反复替换整棵 DOM 的脚本仍不保证无损回写。Regular dynamic DOM can be synchronized from Preview. React/Vue continuous rerenders, Shadow DOM, cross-origin iframes and scripts that repeatedly replace the full DOM still cannot be guaranteed.

网络资源Network resources

外部图片、字体、iframe 和在线脚本不保证离线可用。演示前请改为内嵌资源。External images, fonts, iframes and online scripts may fail offline. Embed resources before presenting.

最终责任Final responsibility

兼容性提示不会阻止导出。分享前需人工检查内容、数据、动画和打印结果。Compatibility notes do not block export. Review content, data, motion and print output before sharing.

FAQ

常见问题Frequently Asked Questions

遇到问题时先从这里排查。Start here when something does not behave as expected.
这是免费的吗？以后可以一直用吗？Is it free, and can I keep using it?

可以。交付版使用本地固定版本的开源 GrapesJS 和 Lucide，不需要订阅、API 或在线账号。只要保留文件，就可以继续使用。Yes. The delivered version uses local fixed copies of open-source GrapesJS and Lucide, with no subscription, API or online account. Keep the file and continue using it.

可以复制到其他电脑直接使用吗？Can I copy it to another computer?

可以。最简单的方式是复制 Edward-HTML-Beauty-Lab.html 单文件版；也可以发送完整 ZIP，解压后运行。Yes. The simplest option is the standalone Edward-HTML-Beauty-Lab.html, or share the ZIP and extract it before use.

为什么选不中某个元素？Why can I not select an element?

它可能被遮挡或嵌套较深。打开左侧图层树，从父级逐层展开并选择。Canvas 内部内容和复杂 SVG 路径只能整体处理。It may be covered or deeply nested. Open Layers and expand from the parent. Canvas internals and complex SVG paths can only be handled as a whole.

为什么下拉选项改完后预览又变回去了？Why did dropdown options revert in Preview?

原页面脚本可能在启动时重建选项。Beauty Lab 会尝试在脚本运行后恢复用户修改，但高度定制的组件仍需人工验证，必要时请让 AI 把选项改成静态 HTML。The original script may rebuild options at startup. Beauty Lab tries to restore your edits afterward, but highly customized components still need review. Ask AI to convert them to static HTML if needed.

如何修改点击按钮后才出现的页面？How do I edit a page that appears only after clicking a button?

切到“预览”，点击原页面按钮打开目标组件，再切回“修改”。Beauty Lab 会同步当前 DOM、显隐、输入和选择状态；随后可在画布或图层中选择普通文字和组件。Switch to Preview, use the original page button to open the target view, then return to Edit. Beauty Lab synchronizes the current DOM, visibility, input and selection state so regular text and components can be selected on canvas or in Layers.

“保存”和“导出”有什么区别？What is the difference between Save and Export?

保存会覆盖当前文件；导出始终新建文件。首次试用或重要材料建议先导出，确认正确后再使用直接保存。Save overwrites the current file; Export always creates a new one. Export first for initial trials or important material, then use Save once confident.

打印 PDF 被裁切怎么办？What if the PDF is clipped?

先切换 16:9 画布检查页面，再在打印窗口选择合适纸张方向、边距为无或最小、缩放为适合页面，并逐页检查预览。Check the page in 16:9 canvas, then choose the correct orientation, no/minimum margins and fit-to-page scaling in the print dialog. Review every page.
